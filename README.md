## The workflow

1. **Measure** — the source site's live HTML + compiled CSS were extracted and audited (black-box, reproducible with `curl`).
2. **Teardown** — findings are written up in the PDF report with evidence tables per design token.
3. **Operationalize** — the teardown data was compiled into the agent prompt, so any AI coding agent can repair a landing page against the same quality bar and paste evidence for every gate.

## Headline findings

- One typeface (Inter), one brand hue in two blue steps (`#3074FE` / `#1838f8`), OKLCH neutral ramp
- Radius scale rooted at `10px` (2xl = 1.8×); blur stepped at 4/8/12/24px; all media locked to 16:9
- Motion library: exactly 7 cubic-bezier curves, entrances 300–600ms @ 60ms stagger, hovers 150–250ms
- Only `transform`, `opacity`, `filter`, `background-position` ever animate
- Animated check micro-interaction fully specified: draw 0.3s (lead 0.64) → fill 0.22s → pop 0.22s @ scale 1.09
